# 抓个大鹅

原创田园风格的网页三消游戏。不是微信《抓大鹅》的官方版本，不使用其代码、图片、角色素材或接口，也不修改原游戏的次数限制。

## 交付范围

- 可直接玩的 H5 网页和单文件离线版。
- 农场、菜园、果园三个场景；36 / 72 / 108 件物品三档难度。
- 七格收获篮，三个相同物品自动消除，清空全部物品后获胜。
- 无限开局、免费撤回、三格寄存、颠锅和找一组提示。
- 六位累计胜场解锁的鹅友、连胜、各难度最快纪录。
- 自动保存当前局、音效开关、减少动效设置、手机触控及键盘可访问的物品列表。
- 所有脚本、图标和素材都在本地。无广告、付费、登录、次数限制或第三方数据上报。

## 直接运行

优先打开交付目录里的 `抓个大鹅.html`，无需 Node.js、插件、网络或安装依赖。

源码版也可以直接打开 `index.html`，请保留同目录脚本和 vendor、assets 文件夹。

需要 HTTP 预览时，使用 Node.js 20 或更高版本：

```sh
node server.cjs
```

默认监听本机 4173 端口；端口占用时会自动尝试后续端口。实际地址见启动输出。服务只绑定本机，不会自动暴露到公网或局域网。

重新生成单文件：

```sh
node build.cjs
```

默认输出到源码文件夹的上一级，也可传入输出文件路径。单文件与源码版的浏览器存储可能相互独立；更换浏览器、网址或清除站点数据后，旧进度不一定保留。

## 验证

```sh
node --test tests/core.test.cjs
```

核心测试覆盖关卡生成、三消、七格边界、撤回、寄存、胜负、存档校验和随机操作。界面另已通过 Chrome / Playwright 桌面和移动触控模拟验证，详细范围见 `TEST-REPORT.md`。

## GitHub Pages

已经准备好 `.github/workflows/pages.yml`，不需要购买插件。

1. 在自己的 GitHub 账号创建仓库，将本源码文件夹的内容放到仓库根目录并推送至 `main`。
2. 在仓库的 Pages 设置中选择 GitHub Actions 作为发布来源。
3. 运行 `Publish Game to GitHub Pages` 工作流。工作流先执行核心测试，再只上传网页运行文件。
4. 部署完成后，使用该工作流实际返回的网址。

实际发布状态以仓库 Actions 中的 `Publish Game to GitHub Pages` 工作流和 `github-pages` 环境为准。发布后的静态网页由 GitHub 托管，不依赖开发者的电脑保持开机。游戏本身不限制游玩次数，托管服务的访问额度仍然适用。

## 微信与集成

本次交付是独立网页游戏，不是已经审核上线的微信原生小游戏或小程序。拿到可访问的 HTTPS 网页地址后，可以作为网页入口分享；在微信内置浏览器中的表现需要使用实际手机验证。

其他网站可以通过 iframe 嵌入；把下面的占位地址替换成实际部署地址：

```html
<iframe
  src="https://YOUR-GAME-DOMAIN/"
  title="抓个大鹅"
  style="width:100%;height:900px;border:0"
  allow="autoplay"
></iframe>
```

如果需要发布为真正的微信小程序、用小程序 web-view 承载或移植到微信小游戏运行环境，还需要你的小程序/小游戏账号、AppID、合适的托管地址，以及微信平台要求的配置与审核。本交付不伪造这些账号或声称已经完成审核；原生小游戏环境也不能直接运行依赖 DOM 的此网页源码。

## 文件结构

- `index.html`：页面结构。
- `style.css`：桌面和手机布局。
- `art.js`：原创物品与鹅友插画。
- `core.js`：独立、可测试的游戏规则和存档校验。
- `game.js`：Canvas 绘制、Matter.js 物理、交互、音效、存档和界面。
- `vendor/`：Matter.js 0.20.0、Lucide 及其许可证。
- `server.cjs`：无依赖本地静态服务。
- `build.cjs`：单文件离线打包。
- `tests/`：规则测试。

## 设计说明与边界

不同场景使用不同的物品组合，不同难度增加种类和堆叠密度。物品由完整三件组随机打乱，并不是预制的固定关卡，因此每次重开可以得到新的一锅。

随机堆叠不承诺每局都能在完全不用道具的情况下通关。不限次的提示会把一组物品提到上层，寄存与撤回允许继续调整；“无限玩”不等于自动通关。

纪录仅保存在当前浏览器，没有云端账号、多人排行榜或跨设备同步。离线模式下音效可用，但浏览器通常要求首次手动开启。设备性能、浏览器版本和实际微信环境可能影响体验。
